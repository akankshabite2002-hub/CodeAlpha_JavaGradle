# CodeAlpha Java Application Using Gradle

# Project Overview

This project demonstrates Java build automation using Gradle. It includes a Java application, JUnit unit tests, dependency management, and a GitHub Actions continuous integration workflow.

# Technologies Used

- Java
- Gradle
- JUnit 5
- Git
- GitHub
- GitHub Actions

# Continuous Integration

The GitHub Actions workflow is configured to run the Gradle build when changes are pushed to the `main` branch or a pull request targets 

The workflow checks out the source code, configures Java and Gradle, and executes the build and tests.
